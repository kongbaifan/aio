# P4：试点准备、验证、迁移与限范围开放

> 父任务共 16 项：GOV-03/05/06/08/09、OPS-03/04/05、UI-08/09/10、REL-01～05。全部待实施。不是到了这里才开始测试；P4 将前面持续产生的证据汇总为可签字的 G5。

## 1. 进入条件与试点边界

- G1/G2/G3/G4 对计划开放的资源、executor、协议、文档类型已有真实证据；未测能力在 API/profile 层关闭。
- 试点仅白名单、低敏/已批准数据、少量模板、只读 MCP 和受控本地计算；真实外部写、任意自助发布仍不默认开放。
- 运营预算、最小审计、应急停止已从 P2 生效。本阶段补完整对账/支持/分享留存/监控/恢复及管理界面。
- 真实历史数据迁移必须先备份与恢复演练；源数据无明确归属时保留受限，不阻塞用全新合成数据试点。

## 2. GOV 治理任务卡

### GOV-03 — 预算账本、结算、价格版本与对账

**位置/契约**：`APP/billing/ledger.py,settlement.py,reconciliation.py`、用量 API；扩展 RUN-10，不重建第二份计费事实。

- [ ] **GOV-03.01** 统一 reserve/charge/adjust/release 事件与稳定幂等键，金额用定点/Decimal 等明确精度而非浮点累计。
- [ ] **GOV-03.02** 保存价格版本、币种、模型/工具/embedding/rerank 数量，provider invoice 与内部估算分开展示。
- [ ] **GOV-03.03** 对失败但可能已计费、流 usage 缺失、provider retry 重复响应记录 unknown/estimate，不当零消费。
- [ ] **GOV-03.04** 定期核对未结算预留、孤儿 Run、延迟用量和取消任务，调整追加记录而非覆写历史金额。
- [ ] **GOV-03.05** 为组织/部门/用户提供获权汇总和告警，不能通过账单 API 看到其他部门的私有 prompt。
- [ ] **GOV-03.06** 验证额度耗尽并发和恢复后结算，设置估算误差安全余量；不承诺上游延迟账单绝无超额。
- [ ] **GOV-03.07** 输出 trial daily/run budget、费用未知阈值和人工对账负责人。

**验收**：GOVTEST-01/02，Run/ledger/provider request 可相互核对。**PR/回滚**：保留账本和预留，暂停新增付费调用，不回滚数据库丢账。

### GOV-08 — Trace、指标、日志与低基数观测

**位置/契约**：`APP/observability/`、manager/executor adapter 指标；关联 ID 与业务正文分开。

- [ ] **GOV-08.01** 在 API→Job→Worker→Gateway→manager/远端→Artifact 建 trace 关联，保留原始 actor 和服务 actor。
- [ ] **GOV-08.02** 定义 API 延迟、队列等待、模型/工具耗时、资源峰值、审批、unknown、清理失败和摄取阶段指标。
- [ ] **GOV-08.03** metric 标签不用 user_id/run_id/原始 URL/文件名/正文，防高基数和隐私泄漏；关联 ID 只进受控日志/trace。

- [ ] **GOV-08.05** 遥测系统不可用时保留权威审计/状态，缓冲有界、失败可见，不无界堆积内存。
- [ ] **GOV-08.06** 用一条完整任务和一条故障任务检查跨度、缺失链路、敏感字段和错误分类。

**验收**：OPSTEST-11、GOVTEST-04/05；指标能定位而非泄漏。**PR/回滚**：减少非必要遥测，不关闭高风险意图审计。

- [ ] **OPS-03.03** 选择一致恢复点并校验对象引用/hash，记录各存储时间差和不可恢复缺口。

## 6. P4 执行顺序与隐藏依赖修正

建议顺序：GOV-03/05/06/08 → OPS-03/04 与 UI-08/09 → UI-10、GOV-09、OPS-05 → REL-01/02/03/05 → REL-04。

原最低依赖表只列局部前置。本细化明确增加以下开放前置而不制造循环：

- REL-04 真正灰度前必须完成 REL-05 回滚演练和 OPS-03 恢复，不仅完成 UI/UAT。
- REL-03 的 UAT 可以先用全新合成数据；若验收迁移数据，必须使用 REL-01 已验证的目标副本。
- 任何正式分享都等待 GOV-06 与 GOVTEST-11，不因 UI-05 已画按钮而提前开放。
- OPS-05 压力环境仍为隔离节点，不在试点中直接对用户任务施加恶意负载。
