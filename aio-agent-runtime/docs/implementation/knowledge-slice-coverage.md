## 重要实现决定

- 浏览器关键词预览不外发 embedding；Worker 的 hybrid 查询必须具备有效模型/预算，不因失败静默降级。
- 查询的候选与文本/向量都先执行当前权限过滤，不能先送模型再删内容；共享KB中的受限文档仍然受限。
- Run 冻结当时获权版本集合上限。更新版本使旧引用不可继续使用，不悄悄改向新内容。
- 模型费用未知与向量结果未知是不同事实：结果已知但usage缺失可用向量并保留费用；结果丢失不盲目重跑。
- 解析器命令/镜像固定，API/Worker只传原始bytes和检查有界结果，不解压/渲染用户文档。
- 删除先撤权再清理，blob引用检查包括其他知识版本、Artifact、上传与待发布workspace，不删除仍被使用的相同hash。

## 本轮修复的边界问题

1. **ZIP原始名称与平台规范化名称**：在Windows，ZipInfo.filename可把反斜杠规范化；验证改为原始名称，避免不同平台检查不同对象。
2. **PDF间接XFA**：不能对IndirectObject的字符串表示查XFA字段；解析实际对象后拒绝已识别活动内容。
3. **上传重试与后台推进**：另一个相同上传已提交且Worker开始解析时，迟到同字节请求仍返回现有版本，不重复Job或误报内容冲突。
4. **完成与心跳竞争**：晚到的lease错误不能回滚已提交的ready索引；优先处理已完成任务并保护终态。
5. **手工重试队列期限**：刷新queued_at而非复用首次过期排队时间；保留真实创建时间与原始审计。
6. **jsdom文件约束**：合成FileList不能更新原生required-file校验。组件测试验证实际File后直接触发提交处理器；保留产品原生约束，未把此单测称为浏览器视觉验收。
