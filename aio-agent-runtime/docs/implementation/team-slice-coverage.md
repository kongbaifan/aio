## 验证与限制必须同时说明

- 合成模型不能证明真实模型规划质量；没有模型“自测通过”式的生产质量结论。
- Team 中间输出不是最终答复；最终回复失败也不会抹掉已执行步骤和已经发生的费用。
- 长 SSE 不依赖最终断开才刷新步骤；UI 读取新的授权服务端投影，拒绝低 revision 覆盖；撤权即清空。
- 复用的是合法共享能力与不可变镜像，不是给员工提供对 API/Worker 主机的 shell。
- 正常步骤内不增加每步 Docker；审批时释放旧 cell，v9 在新代次导入经过核验的文件。文件交接测试不等于进程快照、任意时刻自动续跑或生产 HA。
